# Jenny-Editor

[![License](https://img.shields.io/github/license/mayosteen/Jenny-Editor)](LICENSE)
[![Python](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/)
[![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20Linux%20%7C%20macOS-lightgrey)]()

Jenny-Editor is a Shasavistic Music player and editor built with Pygame SDL.
Jenny-Editor 是一款基于 Pygame SDL 的沙萨维音乐播放器和编辑器。

---

## Features / 功能特性

- Play Shasavistic music files
- Edit note timing and structure
- Keyboard control support

- 播放沙萨维音乐文件
- 编辑音符时间与结构
- 支持键盘操作

---

## Requirements / 运行依赖

- Python 3.8 or higher
- Pygame (SDL backend)

- Python 3.8 及以上版本
- Pygame（SDL 后端）

---

## Installation / 安装方式

bash
git clone https://github.com/mayosteen/Jenny-Editor.git
cd Jenny-Editor
pip install -r requirements.txt

---

## Usage / 使用方法

### English

bash
python main.py 

Use the interface to load a Shasavistic music file and start playback or editing.
通过界面加载沙萨维音乐文件，开始播放或编辑。

---

## Controls / 操作说明

| Key | Function |
|------|------|
| Space | Play / Pause |
| F1 | Start recording |
| F2 | Stop recording |
| 按键 | 功能 |
|------|------|
| 空格键 | 播放 / 暂停 |
| F1 | 开始录制 |
| F2 | 停止录制 |
